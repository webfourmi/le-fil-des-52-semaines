# Cours 0 — Mise en route de la machine (V0.9.7)

Cours préparatoire facultatif pour la Janome Cherry 21 : poste de travail, deux fils, bobinage, pose de la canette, enfilage supérieur, aiguille, remontée du fil et essai sur une chute. Neuf étapes cochables et trois aides aux difficultés.

Accès depuis une carte dédiée en tête de Mes cours et depuis les réglages du cours 1. Une page distincte évite de décaler les 52 semaines, leurs notes et les 52 blocs de la couverture. L’accueil garde le prochain cours annuel et son patchwork. Le cours 0 n’a pas de bloc associé.

La progression utilise les identifiants 90000 à 90008 réservés dans steps (la validation existante accepte déjà ces identifiants). Aucun champ ni numéro de schéma ajouté ; les exports et imports de sauvegarde restent au schéma 4. Les anciennes sauvegardes sans ces coches ouvrent simplement un cours 0 non commencé. Les compteurs des cours annuels filtrent leurs propres identifiants.

La reprise existante fonctionne aussi pour le cours 0. Les neuf étapes cochées donnent accès à la relecture ; aucun projet ou bloc annuel n’est validé. Les textes et le script sont précachés dans le shell V0.9.7 ; les vidéos externes nécessitent Internet et ne sont pas intégrées dans un lecteur.
